# Agent 执行环境的能力边界：2026-11-07

Evidence: https://www.producthunt.com/products/glasshand and https://www.producthunt.com/products/maritime (observed 2026-11-07). Glasshand founder acknowledged QR camera feed support missing; Maritime founder said virtual Android lacks installed apps. Users asked about human takeover, pricing, passwords and device types. These are **public questions**, not representative customer interviews.

Hypothesis: agent execution infrastructure value depends on **capability coverage + recovery handoff + predictable cost**, rather than model quality alone. Counterexample: local devices, existing simulator and cloud VM may already satisfy most users. Two-week experiment: capability checklist with 8 interviews and 5 trials; require >=3 repeat uses and >=2 explicit repeat/paid requests, otherwise reject. See daily report for complete design.
