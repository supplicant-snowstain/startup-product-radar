# Offline Tool Reality Check — 2026-11-21

Hypothesis: independent developers want reproducible, offline validation of recommended tools rather than popularity-based suggestions. Sources: https://pickfit.app/how and https://www.producthunt.com/leaderboard/daily/2026/11/20 . This is a hypothesis, not observed demand.

MVP: allowlisted Docker smoke tests + Python CLI + HTML receipt, no default execution of untrusted code. Interview eight developers about actual failed installs; invite five to trial. Success: three task completions, two repeat users in seven days, two requests for integration, 80% issue recall. Failure: fewer than two repeats or unsafe execution.

Contradiction: pickfit already advertises sandbox testing; differentiation and willingness to pay are unverified.
