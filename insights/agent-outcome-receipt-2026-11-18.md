Status: unvalidated, falsifiable public-market hypothesis.

- Versine proposes passkey-confirmed agent payments; public users question wrong recipients and prompt injection.
- RankSpot and TheBold promise marketing execution or investor access; output counts and meetings are not proof of commercial success.

## 14-day experiment
Target: solo developers and small teams running agent automations. JTBD: verify exactly what an agent changed, who approved it, and whether the outcome was achieved.

MVP: Python standard-library CLI reads **synthetic** JSON run records, generates a static HTML receipt with action digest, approvals, before/after changes and errors. No live accounts, payments or private data.

Week 1: eight interviews about actual incidents in the previous 30 days, prototype, compare existing logs/Git diff. Week 2: five voluntary tests, record completion, time to diagnose and repeat use.

Success: >=3/5 complete the task; >=2/5 repeat use within seven days; >=2 indicate concrete integration intent; median diagnosis time at least 20% shorter than baseline. Failure: <=1 completes or no interviewee can describe a concrete incident. Payment willingness must be tested separately.

Risks: redundant with existing logs, sensitive data leakage, and mistaking a receipt for correctness proof.
