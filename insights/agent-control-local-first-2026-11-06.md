## Two-week falsification: Agent Approval Evidence Pack
Interview 8 small-team agent developers with de-identified examples; build local JSONL/CSV timeline and HTML evidence export, test with 5 teams. Success: >=4 report recent real friction, >=3 reuse export within a week, >=2 express willingness to pay >=$20/month. Failure: <=1 reuses or free native tools fully satisfy need. Avoid confidential logs, credentials and company-specific advice.

## Counterexamples and confounds
