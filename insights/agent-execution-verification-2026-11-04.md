# Agent 可执行性与可验证性：2026-11-04 待验证假设

观察：Scalekit AgentKit 提供授权、受限工具访问与调用记录；Testifly 尝试自动发现并验证 Web 工作流。来源：https://www.scalekit.com/ 、https://testifly.dev/ 。这些是**官方功能描述**，不是独立市场需求或留存数据。

跨产品假设：Agent 的价值不止生成动作，还需要证明动作在正确权限下执行、结果可验收、失败可定位。反例：平台自带的工具审计、CI 与 Playwright 已经满足部分团队；不一定需要独立新产品。

独立 MVP：本地 JSONL 工具事件记录器 + 静态证据查看器；不采集凭据、不依赖私有数据。8 人访谈、5 人试用；成功 ≥3/5 七天内重复使用且 ≥2 人主动要求集成；失败 ≤1 人重复使用。详细方法见 [日报](../reports/2026/11/2026-11-04.md)。
