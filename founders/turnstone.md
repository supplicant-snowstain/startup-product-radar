# Turnstone：从 Agent 使用额度中断发现产品机会（公开叙述）

**2026-11-08 观察；仅记录创始人公开发表的个人经历。**

联合创始人 Aryan Vij 在 Product Hunt 的 2026-11-06 发布讨论中表示，自己频繁使用现有 Agent 时被额度限制打断，同时已购买其他模型订阅但利用不足；因此与 Jai Bhatia 开发 Turnstone，尝试复用现有订阅、在模型限额时自动切换并维持任务上下文。

**证据分级**：创始动机与产品能力属于 CLAIMED；公开发布讨论、用户对本地遥测与模型支持的提问属于 OBSERVED；实际跨模型任务成功率、付费转化、留存、早期 MVP 版本时间线 UNKNOWN。

**值得验证**：是否违反或受限于供应商服务条款？切换时工具状态是否能完整恢复？用户能否接受多账户授权风险？免费模式能否持续？
