# Curated need records

This directory contains only research-backed need summaries. Each `need-*.json` identifies a target user, observed problem, and stable links to reviewed evidence and related products. See `schema/need.schema.json`.

A claim that a need is unmet requires assessment of alternative solutions and contradictory evidence. No unsourced AI suggestions are treated as real user needs. Synthetic fixtures belong in the test suite, never here.
