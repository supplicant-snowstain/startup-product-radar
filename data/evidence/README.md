# Public evidence records

Daily Markdown reports are human-readable. To power the analysis engine, curate independently sourced evidence into one JSON file per observation, following schema/evidence.schema.json.

Additional optional fields for the initial evaluator: dimension (user_need, competitor, differentiation, distribution, pricing or feasibility) and stance (supports, contradicts, context).

Never interpret a source URL as verification of the statement. Verify manually before marking observations trusted. The directory intentionally contains no invented market data.
