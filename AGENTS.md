# Repository agent instructions

This is a public, multilingual (English, Chinese, French) startup-product research site. Preserve the distinction between observations, sourced claims, hypotheses, and verified facts. Never add employer-specific internal information.

For **all** code changes and release requests, read and follow [the radar-release skill](.agents/skills/radar-release/SKILL.md). Use a branch and pull request; run the stated validation gates; merge only with authorization and passing checks; confirm Pages deployment and production acceptance before reporting success. If a tool or browser is unavailable, disclose the missing verification rather than assuming success.
